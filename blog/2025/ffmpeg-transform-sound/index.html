使用ffmpeg将声音从不同设备转移

使用 ffmpeg 通过网络将一台设备的音频传输到另一台设备播放

Apr 18, 2025 Notes linux

Contents

  • 背景
  • 安装ffmpeg
  • 配置mac端
  • 配置windows端

背景

希望通过网络让设备A作为音频输入，设备B作为音频输出。

以mac作为麦克风，windows作为音响为例。

安装ffmpeg

对于mac系统：

brew install ffmpeg

对于windows系统，访问官网，下载发布版本压缩包，解压，并将 bin文件放到环境变量即可。 注意，这里由于还要以来其他dll文件，所以直接执行ffmpeg二进制程序不可取。

配置mac端

配置mac作为发送端：

ffmpeg -f avfoundation -i ":0" -c:a libmp3lame -f rtp rtp://<接收端ip>:<端口>

配置windows端

ffmplay -i rtp://<发送端ip>:端口
