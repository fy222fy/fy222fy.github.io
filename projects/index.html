Research · NSFC-funded2018.09 – 2020.03

Formal Analysis of the FIDO UAF Protocol

FIDO UAF replaces passwords with biometric authentication, but had never been analyzed comprehensively. This project built a general method for formally analyzing such protocols, and an open-source tool that automates it.

  • Extracted the security goals and assumptions of UAF from 500+ pages of standards, and modeled confidentiality, authentication and unlinkability.
  • Proposed a way to model inter-process communication inside a device, distinct from how network protocols are modeled.
  • Proposed a minimal-assumption analysis method and built the open-source verifier UAFVerif, verifying 400,000+ protocol scenarios.
  • Found and classified 4 classes of attacks covering all known attacks, and the minimal assumptions under which UAF is secure.
  • Analyzed 1,856 payment-related apps: 42 apps using UAF carried 2 classes of risk; demonstrated arbitrary-amount transfer attacks on 2 of them.
  • Found a bug in the ProVerif verifier and contributed the fix.

Confidential LLM Inference in TEEs

SecretFlow Cloud (2024) deploys models inside trusted execution environments, so that neither the model nor users’ queries are exposed to the hosting platform.

  • Designed the authentication flow between the user platform and cloud TEEs, and key generation and encrypted transport based on remote attestation.
  • Deployed LLMs in SGX and HyperEnclave with Occlum, Ant Group’s open-source TEE OS.
  • Built the path in which queries are encrypted on the platform, decrypted and computed inside the TEE, and returned encrypted.

Product + algorithms2022.01 – 2023.06

Trusted-Environment-based Cryptographic Computing (TECC)

Heterogeneous TEEs run in one LAN together with MPC: faster than MPC over public networks, and more secure than a single TEE.

  • Proved the privacy of the semi-honest ABY3 protocol under a malicious model, after comparing MPC algorithms.
  • Implemented ABY3 operators and optimized vector XOR, matrix dot product and sorting (4 patents).
  • Adapted operators to SGX and HyperEnclave, deployed to the cloud and onboarded 1 business application.

Product2021.06 – 2021.09

Large Object Storage for OceanBase

OceanBase’s LSM-tree architecture did not support large objects (LOB), and replicas store them at different physical addresses.

  • Flushed LOB data to disk in real time on insert and update.
  • Designed a virtual file system that hides physical addresses from the database layer, keeping replicas strongly consistent.
  • Used tiered indexing to support TB-scale LOB storage.
