## 3. 设计规则

### 3.1 字号（两个方案一致）

| 用途                     | 字号                               |
| ------------------------ | ---------------------------------- |
| 姓名 H1                  | 56px（中文名另起一行，24px）       |
| 亮点数字                 | 36px                               |
| 区块标题 H2              | 28px                               |
| 导语、卡片标题、论文标题 | 20px                               |
| 正文、作者               | 17px                               |
| 导航、按钮               | 16px                               |
| 日期、标签、会议名、说明 | 15px（最小字号，不再使用 12–13px） |

### 3.2 留白与版式

- 页面左右边距 96px；区块间距 56px；不再使用左侧标签栏，区块标题横跨整行。
- 每套配色只用一种底色；分隔只用线条和描边，不使用带底色的面板或卡片。唯一的填充是主按钮。
- 深浅色跟随系统（`prefers-color-scheme`），导航栏提供手动切换按钮。
- 字体建议自托管（Google Fonts 在国内不稳定）。
